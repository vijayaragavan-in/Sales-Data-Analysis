# Sales Data Analysis

## Project Overview

This project analyzes sales transaction data using Python and Power BI to identify important sales trends, performance patterns, and business insights.

## Objectives

- Analyze overall sales performance
- Calculate revenue and profit
- Identify top-performing products
- Analyze regional sales performance
- Compare sales channels
- Analyze customer segments
- Identify monthly sales trends
- Create an interactive Power BI dashboard

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Power BI

## Project Files

| File | Description |
|---|---|
| `sales_data.csv` | Sales transaction dataset |
| `sales_data_analysis.ipynb` | Python/Jupyter Notebook analysis |
| `sales_data_analysis.pbix` | Power BI interactive dashboard |

## Analysis Performed

The project includes:

- Data cleaning
- Data preprocessing
- Exploratory Data Analysis
- KPI analysis
- Product analysis
- Regional analysis
- Sales channel analysis
- Customer segment analysis
- Monthly sales analysis
- Data visualization

## Power BI Dashboard

The Power BI dashboard includes:

- Total Revenue
- Total Profit
- Total Orders
- Units Sold
- Profit Margin
- Monthly Revenue Trend
- Revenue by Product
- Revenue by Region
- Revenue by Sales Channel
- Revenue by Customer Segment
