# 📊 Sales Data Analysis

## Project Overview

Sales Data Analysis is an end-to-end data analytics project designed to analyze sales transaction data and transform raw business data into meaningful insights.

The project uses **Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, and Microsoft Power BI** to perform data cleaning, exploratory data analysis, visualization, KPI analysis, and interactive dashboard development.

The main purpose of this project is to understand sales performance across different products, regions, sales channels, customer segments, and time periods. The analysis helps identify important trends, high-performing areas, and opportunities for business improvement.

---

## 🎯 Project Objectives

The main objectives of this project are:

- To understand and analyze sales transaction data.
- To clean and preprocess the raw dataset.
- To calculate important business Key Performance Indicators (KPIs).
- To analyze revenue, cost, and profit.
- To identify high-performing and low-performing products.
- To compare sales performance across different regions.
- To analyze sales channels and customer segments.
- To identify monthly sales trends.
- To create meaningful data visualizations.
- To develop an interactive Power BI dashboard.
- To generate business insights and recommendations from the analysis.

---

## 🗂️ Dataset Description

The dataset contains sales transaction records with information about orders, customers, products, regions, sales channels, quantities, prices, revenue, cost, and profit.

### Main Columns

| Column | Description |
|---|---|
| Order_Date | Date on which the order was placed |
| Customer_ID | Unique identification number of the customer |
| Product | Product purchased by the customer |
| Region | Geographical region of the sale |
| Channel | Sales channel used for the transaction |
| Segment | Customer segment |
| Quantity | Number of units sold |
| Unit_Price | Price of one unit |
| Discount | Discount applied to the transaction |
| Revenue | Revenue generated from the transaction |
| Cost | Cost associated with the transaction |
| Profit | Profit generated from the transaction |
